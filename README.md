# Autonomous Data Center

A digital-twin simulation of a cloud data center, built so an autonomous system can later manage servers, racks, workloads, cooling, power, and changing demand.

## Problem

Data centers must keep workloads running while power, cooling, and capacity stay within limits. Demand changes, equipment fails, and manual decisions are slow. This project models that environment as a digital twin so scheduling, optimization, prediction, and recovery can be developed and evaluated before they touch a real facility.

## Status

This repository is the project foundation only. The twin itself is not implemented yet. Later work will add the simulation, then scheduling, constrained optimization, demand prediction, event-driven communication, an autonomous agent, failure injection, and quantitative evaluation.
